    这是什么

    这是一份给 2027 届秋招求职者的单文件求职管理看板：把投递记录、进度管道、目标岗位池、Offer 对比、行动待办和简历版本收进一个页面。打开即用、离线可用，数据永远只存在你自己的设备里。
    单文件 HTML零依赖 · 离线可用手机 / 电脑自适应隐私优先

    功能亮点 四组能力 · 从记录到决策

    记录：把秋招的每条线都留住

    • 七阶段管道：已投递 → Offer 逐岗独立记节点日期，进度越深颜色越深
    • 面试题库：多轮面试的题与复盘，跨岗位去重、按频次排序
    • 目标池 + 一键转投递：P0–P3 分级，投了自动生成记录
    • 简历版本 + 投递关联：PDF/Word 存本机，能查投的是哪版

    分析：看清自己打得怎么样

    • 进度统计：全链路漏斗 + 进行中占比环图
    • 节奏与渠道：近 30 天趋势 + 各渠道回音率、复试率
    • Offer 自动对比：自定义维度权重，自动评分给推荐
    • 得分明细：每分可追溯到原始值与权重贡献

    决策：今天该干什么

    • 今天要处理：P0/P1 待办 + 截止倒计时 + 数据体检
    • 凉投标记与重复检测：30 天无更新自动标注，重复投递先提醒
    • 拖拽推进：卡片直接拖入下一阶段，自动记时间线

    数据：随时带走，永不锁定

    • 备份与合并：JSON 导出 / 导入，可选去重合并而非覆盖
    • 日历导出：截止与面试生成 .ics，手机系统提醒
    • 批量导入与搜索：多行文本录历史投递；按公司/岗位/状态筛选

    AI 助手：口述即可，自动填表

    • 自动整理：把面试经历、Offer 待遇口述给 AI，自动结构化填入投递 / 面试 / Offer / 待办等板块
    • 写入前确认：解析结果先预览，勾选确认才落盘，理解错不会误写
    • 模型自选：内置 DeepSeek / 通义 / 智谱 / Moonshot / OpenAI，Key 存本机、直连厂商

    技术实现

    • 单文件零依赖：全部 HTML + CSS + JS 在一个文件内，无框架、无构建、无外部资源，双击即用
    • 纯前端架构：localStorage 持久化 + JSON 一键导出 / 导入，换设备不丢数据
    • 可选云同步：默认完全离线；进阶用户可自配后端，内置分片上传、失败退避重试、sendBeacon 关页兜底、最后修改时间冲突合并
    • iOS 设计语言：毛玻璃分段导航、pastel 徽章、底部上滑表单、SF 系字体栈
    • PWA 可安装：运行时动态生成 manifest 与图标，一键装到手机桌面
    • 全端响应式：≤560px 表格自动转卡片堆叠，手机单手可用
    • 隐私优先：不接任何第三方服务，个人档案与附件永不出本机

    60 秒体验路径

    • 第 1 步：点顶栏「更多操作 → 载入示例数据」，10 秒看懂全部字段的填写效果
    • 第 2 步：切到「投递进度」，看漏斗图、占比环图和七阶段管道如何自动生成
    • 第 3 步：随便改一笔投递的阶段，回到时间线看事件自动落账
    • 第 4 步：点「导出备份」拿到 JSON，再「导入恢复」——数据主权完全在你手里
    • 第 5 步：「清空重置」回到干净模板，开始录入你自己的秋招
