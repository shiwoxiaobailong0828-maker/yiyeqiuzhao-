    这是什么

    一个 HTML 文件，管好你的整场秋招。投递、面试、Offer、待办全在一个页面，数据只存你自己电脑。
    单文件 · 零依赖离线可用隐私优先

    能做什么

    记录

    • 投递：七阶段管道，进度越深颜色越深
    • 面试：题目跨岗位去重、按频次排序
    • 目标池：P0–P3 分级，一键转投递

    分析

    • 漏斗图、占比环图、30 天趋势
    • 各渠道回音率、复试率
    • Offer 自动评分，逐维高亮给推荐

    决策

    • 今天要处理：待办 + 截止 + 体检
    • 30 天凉投自动标注
    • 重复投递先提醒

    带走

    • JSON 导出 / 导入（可合并去重）
    • 截止与面试导出 .ics 到手机日历
    • 批量导入历史投递

    云端同步（可选）

    有什么用

    • 手机和电脑共用一份数据：电脑上录的投递，手机打开就是最新的
    • 换设备 / 清缓存不丢：本地数据被清掉后，可从云端一键拉回
    • 多端不会互相覆盖：以「最后修改时间」为准，旧数据不会盖掉新数据
    • 数据仍然只走你自己的服务器：不经过任何第三方，简历附件只传引用不传正文

    怎么配（四步）

    1. 准备一个接口：项目里已带现成的，两种任选——
      · 本机服务（最快）：双击项目里 云同步服务/启动云同步服务.bat，会打印地址与令牌，同一 Wi-Fi 下手机也能用
      · 公网服务：把 云同步服务/cloudflare-worker.js 部署到 Cloudflare（免费），手机在外面也能同步
      · 也可以自己写：云函数、Vercel、NAS 都行，接口约定见下
    2. 打开配置：顶栏「更多操作 → 云端同步」
    3. 填两项：云端地址（接口 URL）+ 访问令牌（自己定的一串密码，防止别人读你的数据）
    4. 点「保存并测试」：显示已连接即成功；换到另一台设备，填同样的地址和令牌，点「拉取云端数据」即可

    同步规则（不会互相覆盖）

    • 本地改动后约 1 秒自动上传，失败会自动重试
    • 发现云端版本更新时，只在状态栏提示「云端有更新」，不会偷偷覆盖本机
    • 只有你点「拉取云端数据」才会用云端覆盖本机
    • 面板里能看到「上次同步时间 / 本机最后修改 / 云端最后修改来自哪台设备」
    • 每 60 秒自动检查云端；发现更新时可「查看差异」，选择合并两者 / 用云端覆盖 / 保留本机上传
    • 最近 15 条同步记录留在面板里，失败原因一眼可见
    • 可填「同步口令」开启端到端加密：上传的是密文，服务端和拿到文件的人都读不懂（多设备必须同一口令）

    接口约定（自己写后端时照这个来）

    • GET 地址?token=xxx → 返回 {"data": {…全量数据…}}
    • POST 地址?token=xxx → 请求体就是全量数据 JSON，服务端存下来即可
    • 数据超过 90KB 时会自动分片：先 POST action=save-chunk 多片，再 POST action=save-merge 合并
    • token 不匹配应返回 401，避免被陌生人读写

    最小可用的后端示例（Node.js）

    const http=require("http");let store=null;
http.createServer((req,res)=>{
  const u=new URL(req.url,"http://x");
  res.setHeader("Access-Control-Allow-Origin","*");
  res.setHeader("Access-Control-Allow-Headers","Content-Type");
  if(req.method==="OPTIONS")return res.end();
  if(u.searchParams.get("token")!=="你的令牌"){res.statusCode=401;return res.end("no");}
  if(req.method==="GET"){res.setHeader("Content-Type","application/json");return res.end(JSON.stringify({data:store}));}
  let b="";req.on("data",c=>b+=c);req.on("end",()=>{store=JSON.parse(b);res.end("ok");});
}).listen(8080);
    提示：接口必须是 https（或本机 localhost），否则浏览器会拦截。填好后先点「保存并测试」，能连通再长期使用。不配置云端也完全不影响本地使用。

    云端同步 · 详细操作手册

    先澄清一个误解：「跑服务」不需要下载 WorkBuddy，也不需要注册任何账号。 它只是在你电脑上开一个小小的程序，让手机和电脑能互相找到对方。 如果你连这个都不想装，直接看下面 方案 B，全程在网页上点几下就行。

    两种方案怎么选

    对比项方案 A：本机服务方案 B：Cloudflare
    要装东西吗要装 Node.js（免费，5 分钟）不用装，网页操作
    适合场景手机和电脑同一 Wi-Fi手机在外面用 4G 也能同步
    电脑关机后同步不了照常同步
    费用免费免费（个人额度足够）

    方案 A：本机服务（推荐先试这个）

    1. 打开 nodejs.org，下载 LTS 版本，双击安装，一路「下一步」（Windows 用户默认即可）
    2. 打开项目文件夹，进入 云同步服务 目录，双击 启动云同步服务.bat
    3. 会弹出一个黑色窗口，里面显示三行关键信息：
      · 本机地址：http://127.0.0.1:8787
      · 局域网：http://192.168.x.x:8787（手机用这个）
      · 访问令牌：change-me-2027
      这个黑窗口不要关，关了服务就停了
    4. 打开看板 → 更多操作 → 云端同步 → 地址填「本机地址」→ 令牌复制粘贴 → 点「保存并测试」
    5. 手机上：确认和电脑连同一个 Wi-Fi，地址改用黑窗口里那行局域网地址，令牌填同一个

    方案 B：Cloudflare（不装任何软件）

    1. 浏览器打开 dash.cloudflare.com，注册一个免费账号
    2. 左侧 Workers & Pages → Create → Worker → 起个名字 → Deploy
    3. 点 Edit code，把项目里 云同步服务/cloudflare-worker.js 的全部内容复制粘贴进去（覆盖原有代码）→ Deploy
    4. 回到该 Worker → Settings → Variables and Secrets，加两个：
      · 类型选 KV Namespace，变量名填 BOARD，新建一个命名空间绑定
      · 类型选 Secret/Text，变量名填 TOKEN，值填你自定的口令（例如 my-2027）
    5. 复制 Worker 的访问地址（形如 https://xxx.workers.dev），填进看板，令牌填你刚设的 TOKEN

    常见问题

    • 要下载 WorkBuddy 吗？不用。方案 A 只要 Node.js，方案 B 什么软件都不用装。
    • 要花钱吗？两条路都免费。本机服务零成本，Cloudflare 个人用量在免费额度内。
    • 手机填了 127.0.0.1 连不上？127.0.0.1 指的是手机自己。手机要填电脑的局域网地址。
    • 手机和电脑不在一个 Wi-Fi？方案 A 用不了，走方案 B。
    • 点了保存并测试提示失败？先确认黑窗口还开着；地址要带 http://；检查 Windows 防火墙是否拦了 8787 端口。
    • 忘了同步口令？密文无法恢复，只能换口令重新上传（会覆盖云端旧数据）。
    • 不想配这些？完全可以。用「更多操作 → 导出备份」发给自己微信，另一台「导入恢复」，也能手动同步。

    怎么开始

    • 1：点「更多操作 → 载入示例数据」，10 秒看懂结构
    • 2：切到「投递进度」，看漏斗图和管道自动生成
    • 3：随便改一笔投递的阶段，时间线自动记录
    • 4：点「清空重置」回到空模板，录你自己的秋招
    秋招指挥舱 ｜ 数据保存在本机浏览器 localStorage，不上传任何第三方 ｜ 建议定期「更多操作 → 导出备份」
